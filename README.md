
Horizons Coding Collections

Hello. I am Tamilore. This repository contains the projects I worked on during Hack Club Horizons.

Over the few months I created multiple small coding projects while learning game development, programming concepts and how to build complete projects. My main project is a Pokémon-inspired adventure game. I also created several smaller experiments to practice different skills.

## Projects Overview

## Pokémon Adventure Game (Main Project)

My biggest project is a Pokémon-inspired adventure game made with Python and Pygame.
All project were coded with python and edited with VScode


Currently the Pokémon Adventure Game contains:

- A working overworld

- Player movement

- Starter selection

- Pokémon stats and moves

- Battle mechanics

- Type advantages

- Wild Pokémon encounters

The Pokémon Adventure Game currently has one route but it is disabled in later patchess
### Controls

For the Pokémon Adventure Game,

- Overworld controls are:

Arrow keys to move

X to run (requires Running Shoes)

- Battle controls are:

Arrow keys to select moves

Enter to use selected move

### Development Notes

The Pokémon Adventure Game is still in development. Starting from Patch 4 battles are temporarily unavailable because I am rebuilding parts of the system and working on adding the laboratory area.

I used AI to help fix bugs spelling mistakes and troubleshoot some issues in the Pokémon Adventure Game. However the majority of the code and design decisions for the Pokémon Adventure Game were created by me.

# Flashcard Project

I made an English-to-French flashcard application.

The Flashcard Project has the following features:

- Displays flashcards

- Left click buttons to interact

- Click cards to flip between English and French

The Flashcard Project helped me practice:

- Creating simple user interfaces

- Managing program states

- Handling user input


# Pomodoro Timer

I created a simple timer based on the Pomodoro technique.

The Pomodoro Timer has the following features:

- Work timer

- Break timer

- interface

The timer is sped up so that each session only lasts a few seconds for testing.

There are no controls needed for the Pomodoro Timer.


# Dungeon Choice Game

I made a text-based dungeon adventure game.

In the Dungeon Choice Game,

- Players read the story

- Make choices

- Type their response

- Press Enter to continue



# Story Choice Game

I made another text-based adventure project to the Dungeon Choice Game.

In the Story Choice Game,

- The player reads the story

- Makes decisions

- Types choices

- Presses Enter to continue

# Running The Projects

Most projects require:

- Python 3.x

- Pygame (for projects)

To install pygame run:

```bash

pip install pygame

```

To run a project use:

```bash

python filename.py

```
